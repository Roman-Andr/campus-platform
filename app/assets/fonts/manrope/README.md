# Manrope

Source: https://github.com/google/fonts/tree/main/ofl/manrope (downloaded
2026-11-16). SIL Open Font License 1.1 in OFL.txt, included in assets.
Manrope[wght].ttf was instantiated at weights 400/500/600/700 with fontTools
varLib.instancer. Latin and Cyrillic glyph coverage was checked before
bundling. No runtime network requests or google_fonts dependency.
