# Функциональные пробелы и будущие экраны

Этот список связывает UX с исходными владельцами. Наличие задачи в списке
не означает отсутствия её серверной части; статус реализации проверяется
перед началом миграции. Родители и назначения исходных issues сохраняются.

## Универсальные окна и служебные состояния

- Create chooser и выбор подтипа вещи.
- Расширенные фильтры; справочники города/факультета/категории/тегов.
- Gallery/photo picker, перестановка, processing, retry/remove, полный просмотр.
- Preview публикации; сохранить черновик/продолжить/удалить изменения.
- Выбор времени/места, выбор предложения обмена/исполнителя.
- Причина отмены; подтверждение отзыва сессии/блока; конец permitted window.
- Quote/edit/delete, attachment preview, retry отправки, сообщение недоступно.
- Документ/версия, обязательный consent gate, independent optional consent.
- Изменение роли/аудитории, скрытый контент, deleted user, неизвестный enum.
- Offline/reconnecting, локальная очередь, серверный conflict, required update.

У каждого окна есть инициатор, доступное название, focus/Back, основное
и безопасное вторичное действие. Чувствительные коды и персональные
данные не используются в fixtures, runtime-логах и декоративных превью.
