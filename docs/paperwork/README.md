# Документация курсового проекта «Кампус»

Шаблоны программной документации по ЕСПД (Typst): ТЗ, ПЗ (+ титульный лист), ТП, ПМИ, РО и промежуточный отчёт КТ2 (`ОПИСАНИЕ/`).

- Данные проекта (название, код, студент, руководитель) — в общем `data.typ`.
  `ПЗ_Титульный_лист/data.typ` импортирует тот же словарь без внешних ссылок.
- Текст — в `<документ>/sections/*.typ`; места для заполнения помечены `// TODO`.
- Скриншоты и схемы — в `images/`.
- Сборка: `make` (нужен `typst`), PDF появятся в `pdf/`. Пересобираются
  только документы с изменёнными исходниками; дата документа зафиксирована
  в `SOURCE_DATE_EPOCH` в `Makefile`, поэтому повторная сборка даёт
  побайтово тот же PDF. Для новой редакции документов дату нужно обновить.
