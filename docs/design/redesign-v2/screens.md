## A01 · Почта вуза

**Вход:** При старте без сессии; ссылка на объявление сохраняется для возврата.
**Композиция сверху вниз:** Логотип и ценность закрытого сообщества → поле корпоративной почты → ссылки на документы.
**Главное действие:** Получить код
**Вторичные действия:** Изменить адрес; открыть документы.
**Особые состояния:** Недопустимый домен; лимит запросов; нет сети; сервер недоступен.
**Права и ограничения:** Доступен до входа; никаких паролей и социальных логинов.
**Адаптивность:** Компактно: одна колонка и доступный нижний CTA. Широко: ограниченная ширина чтения; master/detail только для списков/чата. При крупном тексте блоки растут, bento превращается в читаемый список.
**Движение:** Единый motion-контракт; reduced motion сохраняет финальное состояние без декоративных сдвигов.

**Компоненты:** AuthFlowFrame, EmailField, PrimaryAction, InlineProblem.
